## Contributing

Contributions to this fork ([Ultra119/photon](https://github.com/Ultra119/photon))—including bug fixes, `block.properties` additions, performance improvements, and lighting refinements—are welcome via GitHub Issues and Pull Requests.

### Guidelines
- Follow the [style guide](docs/style_guide.md) and `.clang-format` configuration (respect `.clang-format-ignore` for `shaders/program/voxy.json`).
- Keep changes compatible with Iris (`CUSTOM_IMAGES`, `COMPUTE_SHADERS`, `SSBO`) and all three dimensions (`world0`, `world-1`, `world1`).
- Verify visual and performance changes in-game with Iris across Overworld, Nether, and End scenes.
- Respect the upstream [LICENSE](LICENSE) terms from SixthSurge's Photon Shaders.
